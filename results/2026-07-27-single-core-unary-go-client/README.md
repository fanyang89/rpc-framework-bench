# Single-core unary benchmark with Go client, 2026-07-27

## Environment

- Linux kernel `7.1.4-200.fc44.x86_64`
- AMD Ryzen 9 9955HX, 16 cores / 32 hardware threads
- 16 physical cores, 32 hardware threads, one socket, NUMA node 0
- CPU frequency governor: `performance`
- Server affinity: logical CPU 15
- Client affinity: logical CPUs 8-14
- Low-volume system services and OpenCode processes remained in the background

This was not a dedicated benchmark host. The measured run used the fixed order
grpc-lite, grpc-go, Tonic, then gRPC C++ in every round. Reporting medians
reduces background noise, but fixed ordering leaves possible time-order bias.
The repository's current `run.sh` rotates framework order for future runs.
All four server processes remained listening on CPU 15 during this measured
run; the three without client traffic were idle at 0.0% observed CPU.

## Workload

- Plaintext HTTP/2
- Official wire-compatible `grpc.testing.TestService/UnaryCall`
- 1 KiB request payload and 1 KiB response payload
- One connection and four closed-loop workers
- 2 second warmup and 10 second measurement
- Five rounds per framework
- One server logical CPU; client on a separate CPU set

## Median Results

| Server | RPC/s | p50 (us) | p95 (us) | p99 (us) |
| --- | ---: | ---: | ---: | ---: |
| grpc-lite | 123796.6 | 31.390 | 48.271 | 84.659 |
| Tonic | 98387.1 | 39.104 | 59.792 | 107.583 |
| grpc-go | 91445.9 | 41.949 | 81.153 | 144.592 |
| gRPC C++ | 88921.4 | 35.747 | 97.824 | 156.205 |

These historical results were generated by the gRPC-Go client. `raw.jsonl`
contains all 20 measured rounds. `summary.json` contains these
medians and percentage differences computed as
`(framework / grpc-lite - 1) * 100` for each metric.

## Interpretation

These numbers apply only to this single-core server, single connection, four
worker, 1 KiB unary configuration. The shared Go client limits grpc-lite to
about 124k RPC/s, versus about 180k RPC/s from its native harness, reducing the
visible differences between servers. The gRPC C++ 1.48.4 system package is old
and should not be treated as representative of current gRPC C++ releases.
